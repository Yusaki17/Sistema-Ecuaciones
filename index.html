📡 Contexto del Problema

Una empresa de infraestructura Cloud gestiona un clúster de N microservicios distribuidos. El rendimiento total depende de las latencias de procesamiento (xᵢ) de cada nodo. Se tiene el modelo lineal de dependencias interno:

Ax = b

Donde A es la matriz de coeficientes de transferencia, b es el vector de latencias máximas permitidas (SLA), y x es el vector de tiempos de cómputo individuales por nodo.

📚 Desarrollo Matemático - Método de Doolittle

🔢 Algoritmo de Descomposición LU

El método de Doolittle descompone la matriz A en el producto de dos matrices triangulares:

// A = L × U
L = matriz triangular inferior (diagonal = 1)
U = matriz triangular superior

// Fórmulas de Doolittle
Para i ≤ j: u[i][j] = a[i][j] - Σ(k=0 to i-1) l[i][k]·u[k][j]
Para i > j: l[i][j] = (a[i][j] - Σ(k=0 to j-1) l[i][k]·u[k][j]) / u[j][j]

🔄 Resolución del Sistema

Una vez obtenidas L y U, resolvemos en dos pasos:

// Paso 1: Sustitución hacia adelante
Ly = b → y = L⁻¹b

// Paso 2: Sustitución hacia atrás
Ux = y → x = U⁻¹y

// Ventaja: O(n²) en lugar de O(n³) para cada nuevo b
