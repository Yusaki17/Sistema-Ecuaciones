📋 ENTREGABLES: Factorización LU

1. Desarrollo Matemático (Doolittle)

// A = L × U (Diagonal de L = 1)
u[i][j] = a[i][j] - Σ l[i][k]·u[k][j]
l[i][j] = (a[i][j] - Σ l[i][k]·u[k][j]) / u[j][j]

Ventaja: O(n³) una vez, luego O(n²) para cada nuevo vector b.

2. Análisis de Ingeniería

Para un clúster con n = 1000 microservicios:

  • LU una vez: ~10⁹ operaciones
  • Cada nuevo b con LU: ~10⁶ operaciones (1000× más rápido)
  • Gaussiana completa: ~10⁹ operaciones por cada b

Esto permite recalcular latencias en tiempo real ante picos de tráfico sin saturar la CPU del balanceador.
